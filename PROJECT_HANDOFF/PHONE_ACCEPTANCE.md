# Galaxy acceptance

1. Verify CI's recorded source and established APK certificate. Upgrade without uninstall/reset; confirm existing apps/domains/plans/settings survive DB migration.
2. Enable Allow Local Yuki control. In the established-signature Local Yuki app enable its bridge capability, inspect state, then change apps/domains/plans/limits/schedules/modes and verify Lockdown's actual state.
3. Test companion enablement, wander, size/position, reduced motion, dialogue and reactions. Verify overlay/guard state on real Android.
4. Exercise begin/confirm/end break. Confirmation before the original minimum countdown must fail; restart/boot cannot bypass the same-boot checkpoint. Existing safe-app protections remain.
5. Disable control and repeat a request: denial must be truthful. A revoked grant, wrong signer, stale digest or changed owner configuration must not silently mutate state. Unknown interrupted mutation must not automatically replay.
6. Compare original protections/settings after restart. Record APK/source identity and each pass/failure. Host protocol tests do not certify actual two-app Binder identities or background lifetime.
