# Phone acceptance (pending)

Use the APK from a green run whose Verified source commit matches the expanded source. Android 8+. Record model, Android version, browser version and commit when reporting issues.

1. Install, open Home/Apps/Websites/Schedules/Settings. Check scrolling, font size, artwork and keyboard layout.
2. Decline each permission first; confirm clear diagnostic, editable settings and no crash. Then enable accessibility and Usage access after disclosures. Allow notifications for warnings. If Android restricts sideload accessibility settings, use App info → Allow restricted settings only if you trust this build.
3. Mark ChatGPT and another AI app Always Allowed. Give a test app one minute. Open it until intervention; verify return Home and Talk to Yuki.
4. Create a currently active schedule affecting that app with unused allowance. Verify immediate scheduled restriction, correct outfit and repeat attempts progressing through four lines/expressions without loops while remaining on Home.
5. Make 23:00–08:00 Monday-only profile; confirm Tuesday morning belongs to Monday's window, and Tuesday evening is allowed. Test midnight 00:00–08:00. Equal start/end is 24 hours.
6. Add a permanent domain and a schedule-only domain. Test supported browser address bar with root and subdomain. Similar suffix impostor must not match. Record hidden URL bar/private-mode limitations; do not assume network firewall behavior.
7. Test overlapping profiles, disable one, change participation, remove domains and uninstall a protected app. No crash; other rules stay intact.
8. Trigger emergency bypass, wait countdown, enter reason/confirm. Strict profile should require at least 60 seconds. Confirm temporary access, expiry and cancellation on reboot. Owner can always edit/disable rules.
9. Restart app and device. Confirm rules/exemptions/attempts survive; confirm service status. Permission revocation must remain recoverable. Examine OEM battery optimization effects.
10. Check usage around local midnight, timezone change and screen-off. Set advance warnings; allow inexact delivery/Doze delays. Verify no duplicate continuous notification flood.

Known gaps: force-stop/uninstall can defeat restrictions; background media and multiwindow are approximate; URL detection is not all-browser/all-network; OEM reliability and actual overlay presentation remain unverified until this checklist is run.
