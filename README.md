# Yuki Lockdown — 1.1.0

A local Android boundary app with owner-selected app limits, scheduled app/site restrictions, permanent exemptions and deliberate emergency bypass. Android 8+; target API35. Version1.1 adds a modern native presentation and restores the approved transparent Yuki exports. Rule evaluation, saved rules and the development signing identity are preserved.

## Update from your Android phone

1. Upload **yuki-lockdown-source-v1.1.0.zip** to the repository root. Keep the old ZIP if present; it is ignored by this update.
2. Replace **.github/workflows/bootstrap.yml** with the separately supplied **bootstrap.yml**. Do not add a second workflow.
3. Inspect the newest **Yuki Lockdown • Bootstrap & Android** run after BOTH uploads. The earlier workflow may run against the old source between uploads; do not install its APK as the update.
4. The new workflow validates the package hash and baseline file hashes, installs the update, builds the app and device-test APKs, runs unit tests and lint, then commits **Update Yuki Lockdown v1.1.0 [skip ci]** and pushes. It refuses to overwrite independent owner source edits.
5. Inspect the green run's **Verified source commit** and download **yuki-lockdown-debug-APK**. Unzip and install app-debug.apk **over your existing app**. Do not uninstall or clear app data. Version code2 and the same development key allow an in-place update retaining rules.
6. Open Settings → **Preview Yuki’s entrance**. Test an actual active restriction after the preview. Try Reduce motion and large fonts.

After the update, expanded repository files remain authoritative. Reruns ignore the ZIP and build current source; they do not overwrite later edits or create repeated update commits. Missing/corrupt archives, unexpected source edits and permission-denied pushes fail clearly. No workflows are generated by the Action. No force pushes.

## What changed

- Fixed bottom navigation with native drawn icons, calmer typography, rounded cards and outlined fields.
- Transparent neutral Yuki on Home; clearer usage bars and honest usage-permission state.
- Bottom-aligned rule editors, native time picker fields, weekday chips and preference switches.
- Yuki enters from the edge over a dimmed Home screen, partially overlapping a floating speech bubble. Native text and buttons remain separate from artwork.
- The real restriction still returns the blocked app Home immediately. The overlay is fully touchable, including visually transparent regions, so taps cannot reach blocked content.
- Optional reduced motion; system-disabled animations are also respected. A clearly labelled preview does not increment reaction counts or change rules.

All six runtime images are exact 768px RGBA PNG exports from the approved Yuki_Lockdown_All_Assets_v1 pack. Original 1254px transparent files are in assets/approved. No artwork was redrawn or background-removal model used. Previous implementation copies were flattened JPEGs with PNG filenames, and the ImageView also painted black; both causes are corrected.

## AI dialogue

This release keeps local authored dialogue and the existing Talk to Yuki redirect. No ChatGPT relay/API integration, network permission, API key or cloud disclosure was added. Optional AI dialogue is a later, separately specified feature; enforcement must remain local and owner-controlled.

## Build / evidence

JDK17, SDK35/build-tools35.0.0, Python3, curl/unzip/sha256sum. Run `./gradlew assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest`; `python3 tools/test_bootstrap.py`; `python3 tools/test_update.py`. Optional disposable emulator: `./gradlew connectedDebugAndroidTest` (StoreTest clears test configuration). Gradle8.11.1/AGP8.9.2, with pinned AndroidX dependencies only in the test APK.

The prior version passed CI and owner installation. This UI candidate has local archive/upgrade/asset validation but has NOT been compiled or device-tested here. GitHub branch creation was denied by the integration (403), and the local environment lacks a complete Android compiler/SDK. A new green CI run is required before installing this candidate.

## Limits / privacy

Website rules inspect known browser URL bars (Chrome, Brave, Edge, Samsung Internet, Firefox); this is not a VPN/network firewall. Hidden bars/private modes/webviews/browser changes can evade detection. UsageStats can approximate multiwindow/background media. Permission revocation, force-stop, uninstall and OEM power management can stop enforcement. Optional alarms can be delayed by Android. No analytics, ads, Internet permission or remote administration.
