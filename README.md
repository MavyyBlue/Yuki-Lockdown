# Yuki Lockdown — Yuki's room 1.6.0 candidate

The app now opens directly into an original cozy blue room with the existing adult animated Yuki. No dashboard, header, bottom navigation or visible launch buttons. Tap Yuki → tap through two greeting lines → choose **Talk / Protected Apps / Sites / Plans**. Each choice opens one bottom-centered, scrollable panel over the same room. Settings/setup are reached through Talk. The top-right **×** validates, saves and returns to dialogue; invalid entries or save failures keep the panel and draft open. Discard remains available. Android Back follows save-and-close for panels; during dialogue it returns to the quiet room.

Existing allowances, exemptions, sites, schedules, setup disclosures, diagnostics, bypass and AI destination remain available through these panels. Settings toggles, floating size and form fields are drafts until the panel is saved. Editors/removal confirmation are embedded too; platform time/permission/preview windows retain their specific tasks. Rotation snapshots retain ordinary form fields/selections and preferences. Bypass reason is never checkpointed; rotation restarts its required wait. Closing a break request never starts bypass.
